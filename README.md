# «Вартавы Часу» / «Хранители Времени»
### Рэспубліканскі інтэрактыўны гісторыка-патрыятычны вэб-квест
> **Распрацавана спецыяльна для конкурсу «ПАТРЫЁТ.by»**  
> Намінацыя: *Камп'ютарныя гульні, творчыя праекты, сэрвісныя распрацоўкі, прадукты з элементамі мультымедыя і камп'ютарнай графікі*.

---

## 🎯 Мэта і актуальнасць праекта

Праект **«Вартавы Часу»** раскрывае ключавыя напрамкі палажэння конкурсу «ПАТРЫЁТ.by»:
1. **Гісторыка-культурная і духоўная спадчына Беларусі:**
   - Полацкая зямля як калыска дзяржаўнасці.
   - 1517 год — падзвіжніцтва Францыска Скарыны і выданне «Псалтыра» на старабеларускай мове.
   - Крыж святой Еўфрасінні Полацкай (1161 г., Лазар Богша).
2. **Гераічнае мінулае і подзвіг беларускага народа:**
   - Мужнасць абаронцаў Брэсцкай крэпасці (1941 г.).
   - Усенародны партызанскі рух (звыш 440 тысяч партызан і падпольшчыкаў).
   - Аперацыя «Баграціён» і вызваленне Беларусі.
3. **Дасягненні ў навуцы, космасе і высокіх тэхналогіях:**
   - Касмічны шлях беларусаў: Пётр Клімук, Уладзімір Кавалёнак, Алег Навіцкі.
   - Палёт першай жанчыны-касманаўта суверэннай Беларусі Марыны Васілеўскай на МКС (2024 г.).
   - Беларускі касмічны апарат (БКА) і дыстанцыйнае зандзіраванне Зямлі.

## 🚀 Ключавы функцыянал і інтэрактыў

- **Сюжэтны рэжым у стылі візуальнай навелы:** дыялогі з гістарычнымі персанажамі (Архіварыус Алесь, Францыск Скарына, Камандзір партызанскага атрада Кастусь, Касманаўт МКС).
- **3 інтэрактыўныя міні-гульні з фізікай і аўдыязваротнай сувяззю:**
  1. *«Друкарскі станок Францыска Скарыны»* — мантаж драўлянай матрыцы, нанясенне фарбы скуранымі мацыкамі, націск вінтавога прэса.
  2. *«Партызанская радыёстанцыя 'Поўнач'»* — ручная настройка частаты 7.15 МГц праз эфірныя перашкоды і рэальнае праслухоўванне і дэкадаванне азбукі Морзэ.
  3. *«Цэнтр кіравання палётамі і спадарожнік БКА»* — ручная стыкоўка касмічнага карабля з МКС з дапамогай манеўровых рухавікоў і каліброўка аптычных датчыкаў.
- **Вэб-аўдыясінтэзатар (Web Audio API):** працуе аўтаномна і афлайн без знешніх цяжкіх файлаў (чысты сігнал Морзэ, механічны лязг станка, ракетныя імпульсы, патрыятычныя фанфары).
- **Поўная двуязычнасць (BY / RU):** імгненнае пераключэнне беларускай і рускай версій інтэрфейсу ў адзін клік.
- **«Кодэкс Нацыянальных Рэліквій»:** віртуальны музей 6 адкрываемых артэфактаў з падрабязнымі гістарычнымі карткамі.
- **«Хранаграф Беларусі»:** інтэрактыўны таймлайн ад 862 года да сучаснасці з фільтрацыяй па катэгорыях.
- **«Віктарына для школ»:** 10 пытанняў з тлумачэннямі для правядзення ўрокаў гісторыі на інтэрактыўнай дошцы.
- **Генератар Імяннога Дыплома «Вартавы Часу»:** дынамічны экспарт у файл выявы (PNG 1200x850) на Canvas альбо вывад на друк з імем, класам і гербавай пячаткай.

## 🛠 Тэхнічны стэк

- **Ядро:** React 19 + TypeScript
- **Зборшчык:** Vite 6
- **Стылізацыя:** Tailwind CSS v4 + Lucide React + Google Fonts (Cinzel, Playfair Display, Inter)
- **Спецэфекты:** Canvas Confetti, Web Audio API Sound Engine, HTML5 Canvas Exporter

## 💻 Запуск і выкарыстанне

### 1. Устаноўка залежнасцей (пры неабходнасці):
```bash
npm install
```

### 2. Запуск у рэжыме распрацоўкі:
```bash
npm run dev
```
Пасля гэтага адкрыйце спасылку ў браўзеры: [http://localhost:3000](http://localhost:3000)

### 3. Зборка для дэманстрацыі і публікацыі:
```bash
npm run build
```
Гатовыя статычныя файлы знаходзяцца ў тэчцы `dist/` і могуць быць апублікаваны на любым бясплатным хостынгу (GitHub Pages, Vercel, Netlify) або запушчаны лакальна праз:
```bash
npm run preview
```
